#  Weather ETL Pipeline

An automated data pipeline that extracts weather data using Python and OpenWeather API, managed by **Apache Airflow**, and containerized with **Docker**.

##  Tech Stack
* **Python**: For data extraction and processing.
* **Apache Airflow**: For workflow orchestration.
* **Docker**: For consistent environment setup.

##  Getting Started
1. Clone the repo: `git clone https://github.com/Saqlain-Amin12/Weather_ETL_pipeline.git`
2. Create a `.env` file and add your `API_KEY`.
3. Start the project: `docker-compose up`
